# 3D Test

A 3D software renderer written in C. It's based on two Tsoding videos, [One Formula That Demystifies 3D Graphics](https://youtu.be/qjWkNZ0SXfo?si=O3oVzwMaaEvvVjZc) and [Graphics API is irrelevant](https://youtu.be/xNX9H_ZkfNE?si=Di6BC6132097y6sW).

The renderer loads a Wavefront OBJ file and renders it to a series of PPM image files.
